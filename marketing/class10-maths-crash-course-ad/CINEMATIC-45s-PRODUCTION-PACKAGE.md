### How to keep the student consistent across clips

Clips 1, 2, 3, 5, 8 and 10 show the same student and the same desk. Generate **clip 2 first**. Save a clear still from it, then attach that still as a reference image when generating clips 1, 3, 5, 8 and 10 (image / reference input). Each prompt also repeats the same description so it works without a reference.

The student is always shown from behind, from the side or as hands only. This keeps the film faceless, avoids the stiff expressions AI faces often produce, and hides small differences between takes.

# DELIVERABLE E – ElevenLabs Voice Settings

### Voice to choose

| Attribute | Recommendation |
|---|---|
| Gender / age | Male, sounds 28–38 |
| Character | Confident, warm, energetic, trustworthy; a television-commercial narrator, not a news reader and not a radio "shouting" announcer |
| Accent | Indian English, with native-sounding Hindi |
| Where to find it | Voice Library → filters: Language *Hindi* or *English*, Accent *Indian*, Gender *Male*, Use case *Advertisement* / *Narration*. Shortlist three voices and test each with lines 4 and 9 before generating the full script. |

The earlier file used "Lauren – Friendly, Comforting and Soft". A soft, comforting voice suits a calm explainer but undersells a price reveal and a call to action, which is why this brief needs a different voice.

### Settings

| Setting | Eleven v4 (the model your earlier file used) | Multilingual v2 (fallback) |
|---|---|---|
| Stability | 40–45 %. Lower gives more acting range; raise to 50 % if the tone changes between takes | 40–45 % |
| Similarity | 75–80 % | 75–80 % |
| Style exaggeration | Current help documentation says v4 has no Style slider; emotion comes from the D4 tags | 20–30 %. Above 40 % the voice becomes unstable |
| Speaking speed | Current help documentation says v4 has no Speed slider; pace comes from tags such as [slowly] and from punctuation. If your screen does show a Speed control, set 1.05 | 1.05 (range 0.7–1.2) |
| Speaker boost | On, if shown | On |
| Output | MP3 44.1 kHz 128 kbps or higher; WAV if your plan allows | Same |

Third-party write-ups disagree on whether Eleven v4 exposes a Speed control, so trust what your own screen shows.

**Model choice:** Eleven v4 first, because it follows the acting tags and handles the emotional shift from fear to excitement. Use Multilingual v2 with block D2 or D3 if v4 mispronounces the Hinglish or speaks a tag.

### Generating in three segments and joining them invisibly

The mood changes twice, so three segments give better acting than one long take.

| Segment | Lines | Mood | Target length |
|---|---|---|---|
| A – Problem | 1–3 | Concerned, then reassuring | about 10.5 s |
| B – Solution | 4–8 | Confident, energetic | about 18.0 s |
| C – Offer and CTA | 9–12 | Excited, urgent, then warm | about 16.5 s |

1. Keep the **same voice, model, stability and similarity** for all three. Changing any of them changes the timbre and the join becomes audible.
2. Generate all three in one sitting. Make 3 takes of each and pick the takes whose energy matches at the joins: the end of A should rise into B, and the end of B should lead into C.
3. Check each take for the four items that must be right: "Neuron Academy", "twenty-nine ninety-nine", "nineteen ninety-nine", and all ten digits of the number.
4. In CapCut, place the segments on one audio track. Trim silence so each join has a 0.25–0.35 s gap; that reads as a natural breath.
5. Add a 0.1 s fade-out and fade-in at each join so there is no click.
6. Select all three and apply the same volume. Use CapCut's *Loudness normalisation* (or match by ear) so no segment jumps in level.
7. If a segment runs long, use *Speed* up to 1.08× with *Pitch* preserved. Beyond that it sounds rushed; regenerate instead.
8. The music bed running continuously underneath hides any remaining difference in room tone.

# DELIVERABLE G – CapCut Final Editing Guide

### 1. Project set-up
1. New project → Ratio **9:16** → Settings: 1080 × 1920, 30 fps.
2. Rename the 12 Seedance clips `01-hook` … `12-endcard` before importing so they sort in order.

### 2. Import and rough cut
1. Import the 12 clips and place them on the main track in order.
2. Trim each to its storyboard length: 3.0 · 4.0 · 3.5 · 4.5 · 3.5 · 3.0 · 4.0 · 3.0 · 6.0 · 3.0 · 4.5 · 3.0. Use the best-moving part of each clip. Timeline end must read 0:45.00.
3. Select all clips → mute clip audio.
4. If the clips are 720p: select each → *Enhance / Upscale* (or scale to fill the frame) so there are no black bars.
5. Clip 3 may be slowed to 0.85× for a calmer feel; clip 4's first half can be sped to 1.2× so the burst lands exactly at 0:10.5.

### 3. Voice-over
1. Import the three narration segments to an audio track; join them as in Deliverable E.
2. Nudge each scene cut to sit just before the first word of its line. The voice leads; move the pictures, not the words.
3. Apply *Enhance voice* / *Noise reduction* lightly; volume so peaks sit around −3 dB.

### 4. Music
1. Add the track on a second audio track starting at 0:00.
2. Cut the music so its main beat drop sits at **0:10.5**. Use *Beat → Auto beat* to see the markers and align scene cuts to them where they fall within 0.1 s.
3. Keyframe the volume: about 30 % at 0:00, 12–15 % under speech, dip at 0:28.5, back up at 0:32.5, fade out 0:44.5–0:45.0.

### 5. Colour consistency
1. Add one *Adjustment* layer over the whole timeline: contrast +8, saturation −5, a slight blue tint in shadows, vignette +10. This makes clips from different generations look like one film.
2. Fix any clip that is visibly warmer or cooler on its own with *Temperature*.

### 6. Subtitles
1. *Text → Auto captions*, language Hindi or English. Auto captions struggle with Hinglish, so correct every line against block D2.
2. Style: Poppins SemiBold, size about 6, white, thin navy stroke, 1–2 lines, maximum 5 words per line. Highlight one key word per caption in gold.
3. Position: just above the lower safe line (about 70 % down the frame).
4. Turn captions **off** during 0:28.5–0:34.5 and 0:37.5–0:45.0; the price and number graphics do that job and should not compete.

### 7. Animated course features (0:15.0–0:28.5)
