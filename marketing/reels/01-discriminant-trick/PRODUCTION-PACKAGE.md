**Mathematics on screen (all checked)**

- For ax² + bx + c = 0 (a ≠ 0), D = b² − 4ac.
- D > 0: two distinct real roots. D = 0: two equal real roots. D < 0: no real roots. (NCERT wording.)
- Example 2x² − 4x + 3 = 0: a = 2, b = −4, c = 3. D = (−4)² − 4(2)(3) = 16 − 24 = −8 < 0, so no real roots.
- The three small graphs match their cases: the parabola cuts the x-axis twice, touches it once, and stays above it.
- The example is an original practice question. It is not labelled as a PYQ anywhere.
